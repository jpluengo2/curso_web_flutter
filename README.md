# Curso Web de Flutter

Este repositorio contiene el código fuente del proyecto "Curso Web de Flutter", una aplicación interactiva diseñada para enseñar los fundamentos y conceptos avanzados de Flutter para la web.

## Descripción

La aplicación es un cuaderno digital (notebook) que presenta lecciones en formato Markdown junto con ejemplos de código interactivos (laboratorios en vivo).

## Características

- Visor de Markdown para la parte teórica.
- Panel de "laboratorio en vivo" para ejecutar y probar widgets de Flutter.
- Interfaz de usuario responsive con paneles redimensionables.
- Carga dinámica de lecciones desde archivos locales.
- Gestión de estado centralizada con Provider.

## Cómo empezar

1.  Clona el repositorio:
    ```sh
    git clone https://github.com/tu-usuario/curso_web_flutter.git
    ```
2.  Navega al directorio del proyecto:
    ```sh
    cd curso_web_flutter
    ```
3.  Instala las dependencias:
    ```sh
    flutter pub get
    ```
4.  Ejecuta la aplicación en modo web:
    ```sh
    flutter run -d chrome
    ```
